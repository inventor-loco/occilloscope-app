OCC Oscilloscope

A browser demonstrator for Optical Camera Communications. It uses a device camera as an optical receiver and plots pixel intensities like an oscilloscope.

Global shutter mode

Every pixel is exposed simultaneously, so one frame yields one sample. Choose a Pixel of Interest (POI) with the X/Y sliders — optionally widening it into a circular Region of Interest with the radius slider — and the averaged R,G,B values are streamed over time.

Rolling shutter mode

Rows (or columns) are read out sequentially, so a single frame already contains a time-modulated signal along the scanning direction. Pick the scanning axis and read the R,G,B profile along it; an optional rectangular ROI averages across the perpendicular axis to reduce noise.

Sensor control

Where the browser and camera allow it (MediaStreamTrack capabilities), the exposure time and ISO/gain can be set manually so the optical signal is not washed out by auto-exposure.
